# PROMPT — The One-Liner Groan-Off

Build a make.fun entry for [The One-Liner Groan-Off](https://make.fun/bounty/u-alfasurya91-the-one-liner-groan-off-5a1febd5) from scratch in this session.

- Task: one line, max 140 chars; program writes `/output/entry.txt`.
- Judge criteria, most important first:
  1. One-line dad joke: a pun/twist a dad would say out loud.
  2. Punchline lands fast and clean; setup + turn inside the single line, no wasted words.
  3. Fresh, not one everyone has heard a hundred times.
  4. Tight, rhythmic wording; easy to say out loud and pass on.
  5. Earned groan: silly enough to laugh at, sharp enough to repeat.

- Text/image is everything that is judged. Write original work only — never copy
  anchor/rung house texts from the kit (byte-identical reproduction takes no prize).
- main.ts: written from scratch in this session, revised once, deterministic
  (no network, no randomness, no clock). Test twice to different output dirs;
  outputs must be byte-identical.
- Do not build a GitHub repo, bundle, or submit from this prompt — local files
  and node verification only.
